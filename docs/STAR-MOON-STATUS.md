## 如何看界面

在 `launcher/` 目录执行 `bun run dev:preview`，然后打开：

`http://127.0.0.1:4187/tests/ui-preview.html`

这是使用**同一份真实 React 界面代码**的隔离浏览器夹具；IPC 被内存模拟器替代，登录和运行时操作被禁用，不写入已安装程序的配置。页脚始终标记模拟状态。可用 `?lang=fr` 等参数检查语言。`?support` 只用于可选推广页面的模拟测试，不会打开或设置真实仓库。

可直接用普通浏览器打开工作区 `outputs/star-moon-preview.html`；这是离线文件，已打开的页面刷新即可加载新版。离线外观只写浏览器专用的 `star-moon-ui-preview-theme` 本地存储键，不写 Electron/Codex 配置。`?theme=dark`/`?theme=light` 可强制预览配色；不传参数时读取已保存的预览月色。`?shell` 跳过基础引导进入全屏首次配置旅程；`?shell&mode=manual` 从手动连接页开始。`?workbench` 只在这个模拟器里跳过引导以检查工作台和设置，不能用于真实程序绕过验收。`?fail-theme` 模拟保存主题失败。所有登录、安装、连接、验收行为仍禁用，不会生成真实成功回执。

这个预览命令只绑定回环地址。它依赖本地开发进程存活，不能把它当成公网部署地址。
